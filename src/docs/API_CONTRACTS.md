# CICADA 2026 — BACKEND & COLLECTOR API INTEGRATION CONTRACTS

**Author:** Senior Frontend Development Engineer & Security UI Architect  
**Branch:** `frontend/integration`  
**Target Roles:** Priyamvadhaa (Tier 1: Local Collector) & Amit (Tier 2: Central SaaS Backend)  
**Security Standard:** NIST SP 800-53 Rev 5 / Zero-Trust Architecture  

---

## 1. ARCHITECTURAL SECURITY INVARIANTS

1. **Zero-Egress of Raw Customer Credentials:**
   Raw customer logs containing credentials, passwords, cryptographic keys, or unmasked PII **must never leave the customer's on-premises perimeter**. Under no circumstances should any SaaS API endpoint accept or return unredacted raw logs.
2. **Local-Only Raw Inspection:**
   Raw logs may only be queried locally via the on-prem enclave API (`127.0.0.1:8080`) over loopback, strictly authenticated with a valid `X-Local-Enclave-Key`.
3. **Cryptographic Proof of Redaction:**
   Every outgoing metadata payload generated by Tier 1 must carry a SHA-256 integrity hash (`validation_digest`) signed by the local enclave.

## 2. TIER 1: LOCAL COLLECTOR API CONTRACTS (Priyamvadhaa)

### 2.1 Local Raw Event Inspection (Local Enclave Only)
*This endpoint must be exposed ONLY on localhost/local network. It must never be proxied to Central SaaS.*

- **Endpoint:** `GET http://127.0.0.1:8080/api/local/raw-event/{eventId}`
- **Headers:**
  - `Accept: application/json`
  - `X-Local-Enclave-Key: <LOCAL_ADMIN_TOKEN>`
- **Response 200 OK:**
```json
{
  "event_id": "evt-auth-9842",
  "source_id": "k8s-ingress-auth-svc",
  "timestamp": "2026-11-20T17:45:12.104Z",
  "category": "identity_access",
  "severity": "high",
  "raw_available_locally": true,
  "local_access_authorized": true,
  "raw_payload": {
    "timestamp": "2026-11-20T17:45:12.104Z",
    "source": "192.168.1.142:54210",
    "path": "/api/v2/auth/login",
    "method": "POST",
    "headers": {
      "Authorization": "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
      "User-Agent": "Mozilla/5.0..."
    },
    "body": {
      "username": "sysadmin@corp.internal",
      "password": "SuperSecretPassword123!"
    }
  }
}
```
- **Error Responses:**
  - `401 Unauthorized`: Missing or invalid `X-Local-Enclave-Key`.
  - `404 Not Found`: Event expired from local circular ring-buffer.
